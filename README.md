## 🧐 프로젝트 배경 및 문제 정의

> **"슬픔을 추스를 여유조차 없이, 유족들은 수많은 서류를 들고 관공서와 금융사를 전전해야 합니다."**

* **Pain Point:** 매년 36만 명의 사망자가 발생하지만, 사후 행정(금융사/통신사/구독 해지)은 극심하게 파편화되어 있어 유족에게 막대한 연차 소모와 감정적 스트레스를 유발함.
* **기존 서비스의 한계:** 정부의 `안심상속원스톱서비스`는 자산 위치를 알려주는 '조회(내비게이션)' 역할에 그치며, 실제 '해지(직접 운전)'는 전적으로 유족의 오프라인 방문에 의존.
* **Goal:** 복잡한 오프라인 방문 행정을 웹 결제 한 번으로 끝내는 **'자율주행 상속 대행 플랫폼'** 구축.

## 💡 핵심 솔루션 (MVP)

### 1. 사용자 맞춤형 온보딩 및 본인인증
* **유입 타겟 분리:** '유족(사후 행정 대행)'과 '1인 가구(생전 디지털 유산 준비)'로 진입로를 분리하여 맞춤형 서비스 제공.
* **합법적 권한 획득:** 간편 로그인 및 PASS/금융인증서를 통한 본인인증으로 전자 위임장의 법적 효력 확보.

### 2. 장바구니 기반 서류 일괄 대행 (BPO)
* **장바구니 UI:** 해지해야 할 금융사, 통신사, OTT 구독 리스트를 쇼핑하듯 일괄 선택.
* **OCR 폼 자동화:** 사망진단서, 가족관계증명서 등 필수 서류를 1회 업로드하면 OCR로 데이터를 추출하여 각 기관의 양식에 자동 병합.
* **우체국 API 연동 대리 발송:** 완성된 서류를 우체국 `e-그린우편` API를 통해 각 본사로 내용증명/등기 실물 발송 대행.

### 3. 진행 현황 트래킹 및 O2O 매칭
* **실시간 대시보드:** 각 기관별 심사 및 해지 완료 타임라인(진행률) 제공.
* **전문가 매칭:** 상속세 신고, 부동산 명의 이전, 유품 정리 및 특수 청소가 필요할 경우 검증된 O2O 전문가(세무사/법무사/업체) 비대면 연결.

## 💰 비즈니스 모델 (BM)

1. **B2C 대행 수수료 (Core):** 해지 기관 수에 따른 묶음 요금제 (예: 5곳 이하 일괄 대행 29,900원).
2. **O2O 중개 수수료:** 전문가 및 유품 정리 업체 매칭 시 발생하는 중개 수수료.
3. **B2B 제휴 납품:** 대형 장례식장 및 상조회사의 'VIP 사후 정리 패키지'로 플랫폼 이용권 납품 (초기 마케팅/CAC 비용 절감).
4. **구독 모델 (미래 확장):** 1인 가구 대상 생전 계정 정보 및 정기 결제 내역을 미리 연동하는 월 구독형 '디지털 유산 금고'.

## 🛠 시스템 아키텍처 및 기술 스택

### Frontend
* **Framework:** `React Native` / `Flutter` (크로스 플랫폼 모바일 앱) & `React` (반응형 웹)
* **State Management:** `Zustand` 또는 `Redux Toolkit`

### Backend & AI
* **Server:** `Node.js` (Express) / `Python` (FastAPI)
* **Database:** `PostgreSQL` (RDBMS), `Redis` (캐싱 및 세션)
* **AI/OCR:** `Naver CLOVA OCR` 또는 `Google Cloud Vision API` (이미지 내 텍스트 정밀 추출)
* **Document API:** `PDF-lib` (추출된 데이터와 서명 이미지를 금융사 PDF 폼에 자동 병합)

### External API & Security
* **우체국 연동:** `우정사업본부 오픈 API (e-그린우편)` - PDF ➔ 실물 우편 자동 변환 및 발송
* **본인 인증:** `KCB` / `Toss` / `PASS` 간편인증 API
* **보안 (Security):** `AES-256` 종단 간 암호화 적용. 민감 서류는 발송 완료 직후 서버에서 영구 파기(Auto-Delete) 처리하여 법적 리스크 원천 차단.

## 🎨 UI/UX 디자인 원칙

* **Color Palette:** 신뢰감과 따뜻함을 주는 `Forest Green` & `Navy Blue`, 배경은 심리적 안정을 위한 `Off-White`.
* **Low Cognitive Load:** 경황이 없고 연령대가 높은 유족을 배려하여, 텍스트 크기를 키우고 한 화면에 하나의 입력만 요구하는 대화형 폼(Conversational UI) 구성.
* **Status Visualization:** 시각적인 프로그레스 바와 직관적인 상태 아이콘을 통해 불안감 해소.

## 🚀 개발 로드맵

* **Phase 1: 컨시어지 MVP (가설 검증)**
  * 모바일 반응형 웹(Web) 런칭.
  * OCR 및 우체국 API 연동 없이 수동(Wizard of Oz)으로 우편 발송 대행.
  * 고객 지불 의사(WTP) 및 결제 전환율(CVR) 데이터 확보.

* **Phase 2: 시스템 자동화 & 스케일업**
  * OCR 엔진 및 우체국 e-그린우편 API 본격 연동.
  * 문서 자동 매핑 서버 구축 및 모바일 앱(iOS/Android) 정식 출시.

* **Phase 3: O2O 확장 및 디지털 유산 금고**
  * 전문가 매칭 시스템 오픈.
  * 1인 가구 대상 생전 데이터 보관 인프라 및 보안(블록체인 분산 저장 검토) 고도화.
